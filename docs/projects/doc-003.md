## 1. 准备工作

### 1.1. 环境安装

#### 方式一：pip安装

```bash
pip install openai
```

#### 方式二：conda安装（推荐）

- 创建conda环境

```bash
conda create -n LLM python=3.10 -y
```

- 激活conda环境
```bash
conda activate LLM
```

- 安装OpenAI SDK
```bash
conda install openai
```

### 1.2. 获取大语言模型API

以[DeepSeek平台](https://platform.deepseek.com/api_keys)为例，必须的参数一般包括:

| 参数名称 | 内容 |
|:---:|:---:|
|api_key| （用户创建后生成，需妥善保管） |
|model|deepseek-v4-flash <br> deepseek-v4-pro|
|base_url|https://api.deepseek.com|

## 2. LLM API 使用基础

> 以OpenAI API为例，Anthropic API 使用方式类似。

### 2.1. 创建API客户端

（可选）关闭系统代理：

```python
import os

#临时清除 socks 代理环境变量，避免 httpx 报错
for var in ("HTTP_PROXY", "HTTPS_PROXY", "ALL_PROXY",
            "http_proxy", "https_proxy", "all_proxy"):
    os.environ.pop(var, None)
```

> 未使用代理可忽略此步

创建API客户端：

```python
from openai import OpenAI

client = OpenAI(
    api_key="<由用户获取后填入>",           # 例如：sk-123abc
    base_url="https://api.deepseek.com"  # 也可以换成其他大模型的API地址，但要与api_key相匹配
)
```

### 2.2. API调用方式

#### 2.2.1. 同步调用模式（标准模式）

- **特点：**
    - 纯粹的输入-输出模式，使用简单便捷
    - 模型生成完成后一次性返回，用户需等待响应

- **示例：**

```python
response = client.chat.completions.create(
    model = "deepseek-v4-flash", # 填入API提供的模型版本，例如deepseek-v4-pro
    messages = [        # 向LLM发送的结构化Prompt
                        # 基本格式：{"role": "", "content": ""}
        {"role": "system", "content": "你是一个AI助手"},   # （可选）系统角色
        {"role": "user", "content": "你好!"},   # 用户输入
        # 其他可选role值
        # ...   
    ],
    # 其他可选参数
    # ...
)
```

- **说明：**

    - `.chat` 表明使用的是文本对话功能，此外还有 `.images`, `.audio`, `.files` 等其他功能
    - `.completions` 是 `.chat` 的具体工作模式
    - `.create` 用于向API发送请求，并获得输出响应
> **注意**：一旦调用 `client.chat.completions.create()`，程序就会向 API 发送请求，并消耗相应token额度。

- **查看结果：**

```python
msg = response.choices[0].message
print(msg.content)
```

#### 2.2.2. 流式响应模式（实时模式）

- **特点：**
    - 实时输出模型生成内容，适合交互场景
    - 需要随时刷新生成内容

- **示例：**

```python
stream = client.chat.completions.create(
    model = "deepseek-v4-flash",
    messages = [
        {"role": "system", "content": "你是一个AI助手"},
        {"role": "user", "content": "你好!"},
        # 其他可选role值
        # ...   
    ],
    stream = True,  # 除了需要将 Stream 置为 True 外，其余参数与同步调用模式相同
    # 其他可选参数
    # ...
)
```

- **查看结果：**

```python
for chunck in stream:
    print(chunck.choices[0].delta.content or "", # 只打印增量，若无增量，则打印不占位的""
          end = "",     # 不换行，使打印结果连贯
          flush = True) # 刷新输出缓冲区，确保实时显示
```

#### 2.2.3. 函数调用模式（工具模式）

- **特点：**
    - 能调用用户自定义的函数，实现多样化功能
> 旧有的 **functions** 接口现已被 **tools** 取代，以下基于均示例程序均基于 **tools** 

- **示例：**

    - 定义函数的结构化信息：
    ```python
    from openai.types.chat import ChatCompletionToolParam
    TOOL_WEATHER: ChatCompletionToolParam = {
        "type": "function", # 固定值
        "function":{
            "name": "get_weather",  # 函数名，自定义
            "description": "获取指定城市的天气信息", # 函数描述，自定义
            "parameters":{
                "type": "object",   # 固定值
                "properties":{  # 函数参数列表，在遵循格式的基础上自定义
                    "city": {"type":"string"},
                },
                "required": ["city"]    # 必需参数列表，从properties中选取，可选
            }
        }
    }
    ```

    > 注意：使用 `ChatCompletionToolParam` 类型注解是为了消除 Pylance/IDE 的类型检查警告，不影响运行时行为。

    - 调用API：

    ```python
    response = client.chat.completions.create(
        model = "deepseek-v4-flash",
        messages = [
            {"role": "system", "content": "你是一个天气预报助手"},
            {"role": "user", "content": "今天北京的天气怎样？"},
            # 其他可选role值
            # ...   
        ],
        tools = [TOOL_WEATHER],
        # 其他可选参数
        # ...
        )
    ```

- **查看结果：**

```python
msg = response.choices[0].message
print("\n========== 工具调用结果： ==========\n")
print(msg.tool_calls)
print("\n========== 大模型输出信息： ==========\n")
print(msg.content)
```
