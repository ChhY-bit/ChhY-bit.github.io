## 前置要求

安装前请确认以下条件：

- [ ] NVIDIA 驱动已安装，终端运行 `nvidia-smi` 可正常输出 GPU 信息
- [ ] 驱动版本 ≥ 550，旧版驱动可能与 Nightly CUDA 后端不兼容
- [ ] Conda 已安装，Miniconda 或 Anaconda 均可

快速检查命令：

```bash
nvidia-smi          # 查看驱动版本和 GPU 型号
conda --version     # 确认 Conda 可用
```

## 安装 Conda

如果系统中还没有 Conda，推荐安装 Miniconda，体积小、安装快。也可以选择 Anaconda 完整发行版，预装了大量数据科学常用包，但体积较大。

### Miniconda

下载并安装 Miniconda，Linux / WSL 环境：

```bash
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
bash Miniconda3-latest-Linux-x86_64.sh
source ~/.bashrc
```

安装过程中按提示操作：Yes → 回车确认路径 → yes 初始化。

Windows 用户前往 [Miniconda 官网](https://docs.anaconda.com/miniconda/) 下载 .exe 安装包，图形化安装即可。

### Anaconda

前往 [Anaconda 官网](https://www.anaconda.com/download) 下载对应系统的安装包，适合新手或需要完整工具链的用户。

### 验证安装

```bash
conda --version
```

应输出类似 `conda 24.x.x`。如果 `conda` 命令未找到，请重新打开终端或执行 `source ~/.bashrc`。

## 安装步骤

### Step 1 · 创建独立 Conda 环境

为避免依赖冲突，建议在独立虚拟环境中安装：

```bash
conda create -n torch python=3.10 -y
conda activate torch
```

推荐 Python 3.10，兼容性最佳，Python 3.11/3.12 也可正常使用。

---

### Step 2 · 通过清华镜像源安装

直接使用 PyTorch 官方源可能因 `pypi.nvidia.com` 连接超时而失败，推荐使用清华大学开源镜像站，速度快且稳定。

```bash
pip install --default-timeout=600 --retries=5 \
    torch torchvision torchaudio \
    --index-url https://pypi.tuna.tsinghua.edu.cn/simple/
```

如果不需要视觉处理和音频处理，可以只安装 `torch`：

```bash
pip install --default-timeout=600 --retries=5 \
    torch --index-url https://pypi.tuna.tsinghua.edu.cn/simple/
```

| 参数 | 作用 |
|------|------|
| `--index-url` | 强制从清华源下载全部包，避免触发 nvidia 官方源 |
| `--default-timeout 600` | 将超时时间延长至 600 秒，应对大文件下载 |
| `--retries 5` | 下载失败时自动重试最多 5 次 |

---

### Step 3 · 验证安装

```bash
python -c "
import torch
print('PyTorch 版本 :', torch.__version__)
print('CUDA 可用    :', torch.cuda.is_available())
print('GPU 名称     :', torch.cuda.get_device_name(0))
"
```

预期输出：

```
PyTorch 版本 : 2.12.0+cu130
CUDA 可用    : True
GPU 名称     : NVIDIA GeForce RTX 5060
```

`torch.cuda.is_available()` 必须返回 `True`，否则 GPU 加速未生效。

---

### Step 4 · 日常更新

Nightly 版本每日构建，建议定期更新以获取最新修复和性能优化：

```bash
pip install --upgrade torch torchvision torchaudio
```

## 常见问题与解决方案

### ConnectTimeoutError 或 pypi.nvidia.com 超时

pip 默认会尝试连接 NVIDIA 官方 PyPI 源，国内网络环境下容易超时。

解决：使用 `--index-url` 而非 `--extra-index-url`，强制走清华源：

```bash
pip install torch torchvision torchaudio \
    --index-url https://pypi.tuna.tsinghua.edu.cn/simple/
```

---

### torch.cuda.is_available() 返回 False

请按以下顺序排查：

1. 检查驱动：`nvidia-smi` 是否能正常输出
2. 检查 CUDA 版本匹配：Nightly 自带 CUDA 运行时，但驱动版本需兼容
3. 重启终端：安装后首次使用可能需要重新激活 conda 环境

---

### 环境冲突，残留旧版 PyTorch

```bash
# 先彻底卸载旧版本
pip uninstall torch torchvision torchaudio -y

# 再重新安装 Nightly
pip install --index-url https://pypi.tuna.tsinghua.edu.cn/simple/ \
    torch torchvision torchaudio
```

---

### 换回稳定版

不推荐对新显卡使用稳定版，大概率遇到 `no kernel image available` 错误。

若确实需要，可尝试：

```bash
conda install pytorch torchvision torchaudio \
    pytorch-cuda=12.4 -c pytorch -c nvidia
```
